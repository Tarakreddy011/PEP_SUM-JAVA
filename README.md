# PEP & Summer Training Resource Repository

A comprehensive collection of study notes, code implementations, practice problems, and concepts compiled during Placement Enhancement Program (PEP) and summer technical training sessions. Designed as an all-in-one reference hub for core Java concepts, Spring Framework ecosystem, Data Structures & Algorithms, SQL, and DevOps fundamentals.

## Core Learning Modules

* **Core Java & DSA:** Implementations covering Java fundamentals, Collection Framework, Java Streams, and practice Data Structures & Algorithms problems (`/JAVA DSA`, `JAVA COLLECTIONS.pdf`, `STREAM IN JAVA.txt`).
* **Spring & Spring Boot Ecosystem:** Code walkthroughs and notes on Dependency Injection (DI), Inversion of Control (IoC), Bean scopes, Bean lifecycle, Component scanning, and handling Circular Dependencies (`/SpringBoot`, `/IOC`, `/Components`, `/Circulardependency`).
* **Database Management:** SQL queries, relational database concepts, and schema scripts (`/SQL`).
* **DevOps & Tools:** Comprehensive guides and notes on version control workflows and cloud/DevOps concepts (`Git_Complete_Notes.docx`, `Cloud Computing & DevOps - Lec 9.docx`).

## How to Use These Resources

1. **Java & DSA Practice:** Browse `/JAVA DSA` and read `JAVA COLLECTIONS.pdf` for quick revisions before technical interviews.
2. **Spring Framework Concepts:** Open the interactive HTML guides (`06-spring-circular-dependency-bean-scope-initialization.html`) or dive into `/IOC` and `/SpringBoot` folders to see Spring annotations in action.
3. **Database & Git Cheatsheets:** Refer to `Git_Complete_Notes.docx` and `/SQL` for quick syntax lookups.
